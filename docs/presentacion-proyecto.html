WA Wali · Perú02 · El problema

Qué busca resolver Wali

Que empezar a pagar sea simple y saber el resultado, claro.

Wali apunta a reducir la fricción del onboarding y la incertidumbre al pagar, especialmente en transacciones cotidianas de bajo monto.

01 / INCORPORACIÓN

Un inicio más sencillo

Guiar a la persona durante el registro y la activación de su wallet, indicándole qué paso sigue.

02 / PAGO

Menos dudas al pagar

Ayudar a completar pagos a contacto y mostrar claramente si el resultado está pendiente, fue exitoso o falló.

03 / CONFIANZA

Una respuesta útil

Dar una referencia e historial cuando corresponde, y orientar el siguiente paso cuando el pago no se confirma.

La reducción de abandono y del tiempo de onboarding son objetivos del proyecto; no se presentan como resultados ya alcanzados.

Stack aplicada al proyecto

Tecnologías utilizadas en la solución.

Frontend y cliente

  • Angular 22 para construir la aplicación frontend.
  • TypeScript 6 para el tipado y la lógica cliente.
  • RxJS 7.8 para operaciones asíncronas.

Backend y pruebas

  • Node.js 26.9 como runtime de backend.
  • node:http para la API local de W1.
  • node:test para las pruebas automatizadas de backend.
